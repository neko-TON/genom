# Borderless Buttons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Кнопки перестают быть коробками: рамка и заливка уходят, остаётся подпись на основном шрифте с подчёркиванием, стрелки из подписей убраны, область нажатия сохранена.

**Architecture:** Task 1 (исполнитель): четыре правила в `front.css`, блок мобильных зон нажатия, шесть подписей в `index.html`, правило и подпись в `404.html` плюс вес шрифта в ссылке на Google Fonts. Task 2 (координатор): браузерный проход с замером зоны нажатия, ревью, мерж, деплой.

**Tech Stack:** Статический HTML/CSS. Проверка: 58 тестов, grep, браузер, прод-curl.

**Spec:** `docs/superpowers/specs/2026-08-31-buttons-design.md`.

## Global Constraints

- Меняются ТОЛЬКО `front.css`, `index.html`, `404.html`. **`app.css` и `console.html` не трогать** — кнопки консоли сознательно остаются с рамками.
- Не менять: цвета-токены, фон, заголовки, тексты страниц, разметку блоков, `og.jpg`, `aria-label` кнопки копирования.
- Класс `mono` снимается ТОЛЬКО с `.btn` и `.lnk`. У `.hd-console` он остаётся.
- Сообщения коммитов заканчиваются строкой:
  `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`
- **Про подсчёты:** ожидаемые числа в шагах проверки уже сверены с текущим файлом. Если фактическое число отличается — НЕ подгонять код под число: сообщить факт и объяснить расхождение.
