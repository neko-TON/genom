# Деплой на Vercel: статика + serverless-симуляция (режим наблюдателя)

Дата: 2026-08-30. Статус: дизайн одобрен пользователем; vercel CLI
авторизован пользователем (аккаунт neko-ton).

## Принципы

Локальный режим (`python3 server.py`, CLI `./genom`) не меняется и остаётся
основным способом разработки; 46 тестов продолжают проходить без Vercel.
Vercel-вариант — публичная витрина: фронт статикой, данные — read-only
serverless-функции, интерактив симуляции недоступен (консоль в
public-режиме, который уже реализован в server.py/app.js). Секретов нет,
env-переменных не требуется.

## Архитектура

- Новые файлы: `api/state.py`, `api/claims.py`, `vercel.json`,
  `.vercelignore`. Существующие файлы не меняются (если импорт `Sim` из
  server.py окажется нечистым — допускается минимальный рефакторинг
  server.py без изменения поведения, с прохождением всех тестов).
- Статика: index.html, console.html, front.css, front.js, app.css, app.js,
  icons.js, favicon.svg, brand-banner.jpg — раздаются Vercel как файлы.
- `.vercelignore`: docs/, tests/, venv/, __pycache__/, .claude/,
  .superpowers/, genom.json, genom (CLI), README.md.

## Детерминированная симуляция

- `api/state.py` (Python-функция Vercel, BaseHTTPRequestHandler-стиль):
  на каждый запрос строит `Sim(seed=GENOM_SEED)` (константа в коде) и
  прокручивает её на `elapsed = now − GENESIS_TS` реального времени с
  дефолтной скоростью узла (эпоха = 60 реальных секунд), затем отдаёт
  JSON, идентичный по форме локальному `/api/state`, с `"public": true`.
- `GENESIS_TS` — константа в коде (момент подготовки деплоя, UTC).
  Следствия (принято): один и тот же момент времени → одно и то же
  состояние у всех посетителей; редеплой с новым GENESIS_TS перезапускает
  мир.
- Защита от роста пересчёта: elapsed капится значением 20160 эпох
  (~2 недели непрерывной жизни); по достижении капа мир замирает на
  последней эпохе (для концепт-сайта приемлемо; лечится редеплоем).
- `api/claims.py` — read-only аналог `/api/claims` на том же
  восстановленном состоянии.
- POST-эндпоинты (`/api/control`, `/api/trade`, `/api/claim`, `/api/gov`)
  на Vercel отсутствуют. Консоль в public-режиме их не вызывает
  (существующее поведение app.js: `showSim = !live && !s.public` и т.д.);
  если при проверке что-то интерактивное всё же торчит/бьётся об
  отсутствующий эндпоинт — добивается на этапе браузерной проверки
  минимальными правками app.js за флагом public.

## vercel.json

- Python runtime для `api/**`; в бандл функций включается server.py
  (`includeFiles`), т.к. функции импортируют из него Sim.
- Статика из корня; `/` → index.html (дефолт Vercel для корневого
  index.html); никаких rewrites для /api (файловая маршрутизация Vercel).

## Деплой и приёмка

1. Юнит-проверка детерминизма локально: два последовательных построения
   состояния для одного и того же момента дают идентичный JSON; для
   момента t+60с — epoch на 1 больше. Оформляется скриптом/тестом,
   запускаемым локально (не ломая существующие 46).
2. `npx vercel --prod --yes` (проект `genom`, аккаунт уже залогинен).
   Деплой выполняется только после явного «да» пользователя на публикацию
   конкретного билда (запрос в чате перед первым прод-деплоем).
3. На проде: `GET /api/state` дважды с интервалом ≥10 минут (эпоха публичного мира = 10 мин) — epoch
   продвинулся; лендинг показывает живые цифры (count-up при public
   отключён — существующее поведение); консоль — витрина без
   sim-контролов; мобильная ширина ок; ноль ошибок консоли браузера.
4. Локально: 46/46 тестов как были.
