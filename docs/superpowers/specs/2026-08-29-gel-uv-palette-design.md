# Палитра «Gel & UV»: биотех + Robinhood

Дата: 2026-08-29. Статус: вариант A одобрен пользователем по визуальным
макетам в чате.

## Идея

Тёмная лабораторно-терминальная база сохраняется; сине-ледяная ось
заменяется на **гель-зелёную** (электрофорезный гель / зелёная свеча
Robinhood), вторичный акцент — **УФ-фиолетовый** (подсветка геля
ультрафиолетом). График unit value становится «гель под УФ»: реальная
линия зелёная, теневая — фиолетовый пунктир. Падение — красно-оранжевый
в духе Robinhood.

### Захардкоженные цвета

Правило: канал 171,224,255 → 99,245,166 (альфы сохраняются); тёмные
сине-чёрные базы → зелёно-чёрные той же светлоты.

- front.css: все `#030609` → `#020804`; все `rgba(171,224,255, α)` →
  `rgba(99,245,166, α)`; `rgba(4, 8, 15, .92)` → `rgba(3, 10, 6, .92)`.
- app.css: `#041018` (3×) → `#04140b`; `rgba(171,224,255, α)` →
  `rgba(99,245,166, α)`; `rgba(3, 6, 9, α)` → `rgba(2, 8, 4, α)`;
  `rgba(82, 223, 162, α)` → `rgba(53, 230, 107, α)`;
  `rgba(255, 100, 120, α)` → `rgba(255, 90, 60, α)`;
  `rgba(255, 196, 107, α)` → `rgba(255, 184, 77, α)`;
  `rgba(26, 95, 176, .16)` → `rgba(157, 123, 255, .16)`;
  `#ffb3bd` → `#ffb5a3`; `#d99aa4` → `#d9a08f`.
- front.js: `color: [171, 224, 255]` → `[125, 245, 170]`;
  `hue: rand(190, 320)` → `rand(100, 290)` (искры из сине-фиолетового
  диапазона в зелёно-фиолетовый); `rgba(0,0,0,0.14)` не трогать.
- app.js `drawChart`: `rgba(171,224,255,.08)` → `rgba(99,245,166,.08)`;
  `rgba(171,224,255,.2)` → `rgba(99,245,166,.2)`;
  `rgba(77,163,255,.55)` (теневая линия) → `rgba(157,123,255,.55)`;
  `"#abe0ff"` (реальная линия) → `"#63f5a6"`.
- favicon.svg: подложка `#050A12` → `#020804`; штрих `#ABE0FF` → `#63F5A6`.

### Что не меняется

Шрифты, вёрстка, тексты, логотип-геометрия (он перекрасится сам через
currentColor), brand-banner.jpg (тёмный, лежит под вуалью). Опционально на
этапе браузерной шлифовки допускается ОДНО добавление: CSS-фильтр на
`.pg-banner` (hue-rotate в сторону зелени, например
`filter: hue-rotate(-60deg) saturate(.8)`), только если синева баннера
визуально спорит с новой гаммой; решение принимает координатор по
скриншоту.

## Критерии приёмки

1. Ни одного вхождения `171, 224, 255` / `171,224,255` / `#abe0ff` /
   `#4da3ff` / `#030609` / `#041018` в front.css, app.css, front.js,
   app.js, favicon.svg (регистр любой).
2. `node --check` обоих JS; полный прогон тестов 46/46 (страховочный).
3. Браузер: лендинг и консоль в новой гамме, контраст текста сохранён,
   график = зелёная линия + фиолетовый пунктир, бейджи good/bad/warn
   различимы, поток цифр зелёный с зелёно-фиолетовыми искрами, фавиконка
   зелёная. Скриншоты пользователю.
