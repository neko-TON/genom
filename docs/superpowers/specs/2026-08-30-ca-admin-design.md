# CA-плашка на главной + админка мгновенной смены контракта

Дата: 2026-08-30. Статус: дизайн одобрен пользователем (место — hero под
кнопками; хранилище — Vercel Edge Config; сначала тест значением "test").

## Принципы

Изменение значения в админке долетает до всех открытых вкладок прода
как правило за ≤6 секунд без перезагрузки. Значения секретов (API-токен Vercel,
админ-секрет) устанавливает только пользователь — через `vercel env add`
или дашборд; в чат/код/репозиторий они не попадают. Локальный режим
(`python3 server.py`) не ломается: эндпоинта `/api/ca` там нет — плашка
скрыта; тесты 51/51 остаются зелёными, новые — добавляются.

## Хранилище

Vercel Edge Config, подключённый к проекту `genom` (env `EDGE_CONFIG` —
connection string вида `https://edge-config.vercel.com/<id>?token=<t>`).
Один item: `ca` (строка). Пользовательская настройка (однократно, руками):

1. Дашборд Vercel → Storage → Create Edge Config → подключить к `genom`.
2. Account Settings → Tokens → создать API token.
3. `npx vercel env add VERCEL_API_TOKEN production` и
   `npx vercel env add ADMIN_SECRET production` (значения вводит
   пользователь в терминале; ADMIN_SECRET он придумывает сам).

## `GET /api/ca` (api/ca.py)

- Парсит `EDGE_CONFIG` из env; читает
  `GET https://edge-config.vercel.com/<id>/item/ca?token=<t>` (urllib,
  stdlib). Ответ: `{"ca": "<строка>"}`; отсутствие item/пустая строка/
  отсутствие env → `{"ca": null}` (HTTP 200 всегда — фронт не шумит).
- `Cache-Control: public, max-age=2`.

## `POST /api/admin` (api/admin.py)

- Тело: `{"secret": "...", "ca": "..."}`. Секрет сравнивается с env
  `ADMIN_SECRET` через `hmac.compare_digest`; несовпадение/пустой env →
  401 `{"ok": false}`.
- Валидация `ca`: строка после `strip()`, длина 0–80, только печатаемые
  ASCII; пустая строка легальна (означает «убрать плашку»).
  Невалидно → 400.
- Запись: `PATCH https://api.vercel.com/v1/edge-config/<id>/items` с
  `Authorization: Bearer <VERCEL_API_TOKEN>`, upsert item `ca`
  (id берётся из `EDGE_CONFIG`). Ошибка Vercel API → 502 с текстом.
- Успех → `{"ok": true, "ca": "<значение>"}`.

## Плашка на главной (index.html + front.css + front.js)

- В hero, сразу после `.hero-act`: скрытый по умолчанию блок
  `<div class="ca-line mono" id="caLine" hidden>` с текстом
  `CA: <span id="caVal"></span>` и кнопкой `<button id="caCopy">` —
  иконка/подпись COPY.
- Стиль: mono 12px, тонкая рамка `--line-2`, значение цветом `--ice` со
  свечением `--glow-gs`; на мобильных адрес переносится/обрезается
  посередине с сохранением начала и конца (CSS/JS-эллипсис), кнопка —
  тап-таргет ≥32px. COPY копирует ПОЛНОЕ значение
  (`navigator.clipboard`, фолбэк — временная textarea + execCommand);
  успех — кнопка на ~1.5с меняется на COPIED.
- front.js: `fetch("/api/ca")` при загрузке и каждые 5с (таймер отдельный
  от sim-поллинга, за существующими паттернами файла); при `ca` непустом
  — показать плашку и обновить текст, при `null`/ошибке сети/404 —
  скрыть. Никаких ошибок в консоли браузера при локальном запуске
  (fetch-catch глотает).

## Админка (admin.html)

- Статичная страница `/admin.html`, нигде не слинкована, стиль консоли
  (тёмная, mono). Элементы: поле «admin secret» (type=password,
  сохраняется в localStorage), поле «contract address», кнопка APPLY,
  строка «current: <значение>» (populated из `/api/ca`), строка статуса
  (ok / unauthorized / error текстом).
- APPLY → POST `/api/admin`; после успеха перечитывает `/api/ca`.
- Локально страница откроется, но APPLY честно покажет ошибку (нет env) —
  допустимо.

## Тесты (tests/test_ca_admin.py)

Чистые функции выносятся и тестируются без сети:
- `parse_edge_config(url)` → (id, token); мусор → None.
- `validate_ca(raw)` → нормализованная строка или None: "test" ✓,
  " 0xAbC…64симв " ✓ (обрезка пробелов), 81 символ ✗, юникод/управляющие ✗,
  "" ✓ (легальная очистка).
- Секрет-проверка: правильный/неправильный/пустой env.
Сетевые вызовы в функциях изолированы так, чтобы юнит-тесты их не
требовали. Итог локального прогона: 51 старый + новые, все зелёные.

## Приёмка

1. Локально: полный прогон тестов зелёный; лендинг без /api/ca не шумит
   и не показывает плашку.
2. Прод после деплоя и настройки env: пользователь вводит в админке
   секрет и значение `test` → на главной в течение ≤6с появляется (обычно ≤6с)
   `CA: test` с работающей кнопкой COPY (проверка копирования — вставкой).
3. Смена значения в админке на другое → все открытые вкладки обновляют
   плашку за ≤6с без перезагрузки.
4. Неверный секрет → 401, значение не меняется.
5. Ноль ошибок консоли браузера на проде и локально.

## Вне объёма

Аутентификация сложнее секрета, история изменений, множественные поля,
rate-limit, показ CA в консоли/футере, локальный write-путь.
