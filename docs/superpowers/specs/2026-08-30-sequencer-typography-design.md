# Типографика «Sequencer» + лёгкое свечение текста

Дата: 2026-08-30. Статус: дизайн одобрен пользователем по мокапам в
visual companion (выбор B «Sequencer» из трёх направлений, затем
утверждён уточнённый мокап со свечением).

## Принципы

Ни одно слово не меняется. Разрешено оборачивать существующие фразы в
инлайн-элементы (символы не меняются) и добавлять чисто декоративные
узлы с `aria-hidden="true"`. Единственные новые видимые строки —
технические ярлыки `SEQ 01`…`SEQ 04` на декоративных штрих-кодах.
Свечение — статичный `text-shadow` (не motion, работает всегда);
всё, что мигает или печатается, — только внутри
`@media (prefers-reduced-motion: no-preference)` и за флагом `REDUCED`
в JS. Интенсивность свечения капится: зелёный alpha ≤ .3, УФ ≤ .4.

## Токены (front.css `:root`, продублировать в app.css `:root`)

```css
--glow-g:  0 0 22px rgba(99, 245, 166, .24);  /* гель-зелёная дымка */
--glow-gs: 0 0 14px rgba(99, 245, 166, .38);  /* сильнее, для мелких акцентов */
--glow-uv: 0 0 16px rgba(157, 123, 255, .40); /* УФ-отсвет маркеров */
```

## Лендинг (index.html + front.css + front.js)

1. **Hero.** `h1` получает `text-shadow: var(--glow-g)`; строка-плашка
   `.hl` — `text-shadow: none` (тёмный текст на зелёной заливке не
   светится). После последней строки `h1` — декоративная каретка
   `<span class="type-caret" aria-hidden="true"></span>`: прямоугольник
   11×3px, гель-зелёный, `box-shadow` свечение, блинк
   `steps(1)` 1.1s (в no-preference; в reduce — скрыта совсем).
2. **Титулы секций 01–04 (`.t1`).** Статично: `text-shadow: var(--glow-g)`.
   Динамика «допечатывания»: front.js за флагом `!REDUCED` один раз при
   первом входе секции во вьюпорт (IntersectionObserver) оборачивает
   каждый символ `.t1` в `<span>` со staggered-задержкой
   (opacity `steps(1)`, суммарно ~0.7s), `<br>` сохраняются; перед
   оборачиванием на `.t1` выставляется `aria-label` с полным текстом.
   При `REDUCED` или без JS титулы статичны и полны.
3. **Штрих-код чтения.** Под каждым `.t1` — декоративный блок
   `<div class="seq-rule" aria-hidden="true">` : 14–18 вертикальных
   тиков (чередование зелёный/УФ, разной высоты и прозрачности, как в
   утверждённом мокапе) + mono-ярлык `SEQ 0N` (N = номер секции,
   letter-spacing .3em, цвет `--mute`).
4. **Mono-лейблы блоков** (`.flow-title` в обоих блоках): `::before`
   с `content: "▸ "`, УФ-цвет + `--glow-uv`; сам лейбл — цвет `--ice`
   с `--glow-gs` на 80% непрозрачности.
5. **Акценты в абзацах.** Существующие фразы оборачиваются в
   `<em class="seq-hl">` (стиль: не курсив; цвет `--ink`,
   `border-bottom: 1px solid` зелёный 55%, `text-shadow: var(--glow-gs)`).
   Точный список фраз (символы не менять): `3% tax` (hero-абзац),
   `MandateGuard` (hero-абзац), `80%` + `13%` + `7%` (шаг 01 «A 3%
   charge on every trade»), `the epoch is voided` (шаг 04).
6. **Строка данных.** Значения `.strip b` — `text-shadow: var(--glow-gs)`;
   существующий курсор `▌` в `.strip-state` — тот же glow.

## Консоль (только app.css; console.html и app.js не трогаются)

- `.wordmark` — `text-shadow: var(--glow-g)`; `.wordmark em` — УФ-свечение.
- `h2 .cn` (ярлыки карточек) — `::before` `content: "▸ "` УФ + `--glow-uv`;
  сам `.cn` — `--glow-gs`.
- `#topStats` значения и `.pill` — `text-shadow: var(--glow-gs)`.
- Токены свечения дублируются в app.css `:root` (console не подключает
  front.css). Никаких новых анимаций в консоли.

## Критерии приёмки

1. Браузер, десктоп: hero светится мягко (плашка `.hl` — без свечения),
   каретка мигает; титулы 01–04 «допечатываются» при первом появлении;
   под ними штрих-коды с `SEQ 0N`; ▸ у mono-лейблов; акценты подчёркнуты
   и светятся; консоль — светящиеся шапка/ярлыки/значения.
2. Эмуляция reduced-motion: каретка скрыта, титулы статичны и полны,
   свечение остаётся (оно статично) — проверка код-ревью: блинк и
   stagger-анимация только в no-preference media, JS-обёртка за `REDUCED`.
3. Слова не изменены: `lynx -dump`-эквивалент текста страниц идентичен
   до/после, за вычетом добавленных `SEQ 01`…`SEQ 04` (aria-hidden).
4. `node --check front.js`; тесты 46/46; ноль ошибок консоли браузера;
   мобильный (375px) — штрих-коды не ломают сетку, каретка не переносит
   строку.
