# Лендинг: два новых блока, микро-анимации, воздух

Дата: 2026-08-29. Статус: дизайн одобрен пользователем по мокапу в чате.

## Принципы

Новые блоки — визуализации УЖЕ заявленных механик; их подписи либо дословно
реиспользуют существующие фразы лендинга, либо являются сухими
ярлыками-заголовками. Ни одного нового утверждения. Тексты существующих
секций не меняются. Консоль и бэкенд не трогаются. Все новые анимации
отключаются при `prefers-reduced-motion` (CSS media + существующий флаг
`REDUCED` в front.js).

## Блок 1 — «THE 3% BLOODSTREAM» (после hero, перед #how)

Секция без номера (существующая нумерация 01–04 не сдвигается): mono-титул
`THE 3% BLOODSTREAM`, инлайн-SVG: слева узел `EVERY TRADE / pays 3%`,
три кривых русла к правым узлам:

- `80%` → `GenomVault — the holders' basket`
- `13%` → `the agent's operations`
- `7%` → `the protocol`

По руслам непрерывно бегут частицы (CSS `offset-path` + `@keyframes`;
НЕ SMIL — чтобы глушилось media-запросом): 4 частицы по руслу 80%, 2 по
13%, 1 по 7% — плотность потока пропорциональна доле. Подпись под блоком —
дословный реюз строки шага 01: `No one needs to lift a finger — the stream
never pauses.`

## Блок 2 — «LIMITS IN THE DNA» (после #how, перед #proof)

Mono-титул `LIMITS IN THE DNA`, инлайн-SVG: двойная спираль (стиль
логотипа), пять перекладин с мягкой поочерёдной пульсацией (CSS opacity
keyframes, delays), подписи перекладин — дословно цифры мандата из шага 04:

1. `WEIGHT ≤ 35%`
2. `POSITION ≥ 5% OR ZERO`
3. `TURNOVER ≤ 20% NAV`
4. `ONE REBALANCE PER EPOCH`
5. `CASH 0–100%`

Подпись блока — дословный хвост шага 04: `…the epoch is voided and the
basket does not move.` (в форме `Any failing vector: the epoch is voided
and the basket does not move.` — допускается только этот вариант сборки из
существующих слов).

## Микро-анимации (front.css + front.js)

- Шаги механики `.ledger li` и карточки `.w-col`: hover → `translateY(-3px)`
  + номер `.no` подсвечивается `--ice`; transition ≈ .3s.
- Параллакс `.hero-ghost`: `translateY(scrollY * 0.08)` в passive
  scroll-листенере; только при `!REDUCED`.
- Count-up строки данных: при ПЕРВОМ успешном `/api/state` значения
  EPOCH/NAV/UNIT/RUNWAY анимируются от 0 до факта (~0.8s,
  requestAnimationFrame), дальше — обычные обновления; только `!REDUCED`.
- Кнопки `.btn`: hover-сдвиг заливки (существующий стиль дополняется
  transition; без изменения цветов).

## Воздух и упрощение (front.css)

- Вертикальные отступы секций: `.sec` top-padding 120px → 150px.
- `--line` приглушается: alpha .12 → .09 (только front.css; app.css не
  трогаем).
- `.kpi`-колонка шагов скрывается на экранах ≤760px.
- `.worst` увеличенный gap между колонками (30 → 42px).

## Критерии приёмки

1. Оба блока рендерятся между нужными секциями; частицы бегут, перекладины
   пульсируют; при эмуляции reduced-motion анимации статичны (проверка
   код-ревью: все новые keyframes обёрнуты в
   `@media (prefers-reduced-motion: no-preference)`, JS — за флагом REDUCED).
2. Ни один существующий текст не изменён (diff по текстовым узлам старых
   секций пуст); новые тексты — только перечисленные выше.
3. `node --check front.js`; тесты 46/46; ноль ошибок консоли браузера;
   лендинг «дышит» (отступы), ховеры работают; скриншоты пользователю.

## Вне объёма

Консоль, тексты существующих секций, бэкенд, новые данные в API, звуки,
скролл-джекинг.
