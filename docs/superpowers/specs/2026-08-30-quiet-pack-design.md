# Пакет «Тишина»: убрать визуальный шум (менее «ИИшный» вид)

Дата: 2026-08-30. Статус: дизайн одобрен пользователем (диагноз —
«визуальный шум»; направления подтверждены).

## Принципы

Характер сайта (лаборатория, гель/УФ палитра, mono-теги) сохраняется.
Убираются повторяющийся декор, повсеместное свечение текста, самый шумный
анимационный эффект и половина фоновых частиц. Тексты не меняются
(удаление декоративных строк `SEQ 0N` и `LIM-0N`/номеров карточек — не
текст, а декор). Единственный «фирменный» декоративный элемент, который
остаётся, — мигающая каретка в hero.

## 1. Декор — долой

- index.html: удалить 4 блока `.seq-rule` (штрих-коды с `SEQ 01–04`);
  удалить `span.gene-code` (LIM-01…05) из 5 генных карточек; удалить
  `span.mc-no` (00…06) из 7 карточек механики.
- front.css: удалить правила `.seq-rule*`, каскад
  `.sec-head.rv.in .seq-rule i*` и `@keyframes tickin`; удалить
  `.flow-title::before` (маркер ▸); удалить правила `.gene-code`,
  `.mc-no`.
- app.css: удалить `.cn::before` (▸ в консоли).

## 2. Свечение — только там, где свет

Убрать `text-shadow` со всех текстов и `box-shadow` со шкал карточек:
front.css — применения на `.hero-in h1` (и парное `.hl { text-shadow:
none }`), `.sec h2`, `.flow-title`, `.seq-hl`, `.strip b`,
`.strip-state .cursor`, `.gene-val`, `.mc-tag`, `.gt-fill`, `.gt-cap`,
`.gt-dot`; app.css — блок `sequencer glow (console)` целиком
(`.wordmark`, `.wordmark em`, `.cn`, `.top-stats b`, `.pill`).
Токены `--glow-*` в `:root` обоих файлов остаются (на будущее).
Свечение СОХРАНЯЮТ: каретка `.type-caret` (box-shadow), линия
`.scroll-progress`, частицы диаграмм (`.fd`, `.fdm`), canvas-ДНК.

## 3. Фон тише

front.js: `particleCount: window.innerWidth < 760 ? 320 : 700` →
`? 160 : 350`.

## 4. Минус самый шумный эффект

front.js: IIFE `typeOn` (допечатка титулов) удаляется целиком.
front.css: правила `.sec-head h2.t-on .tch` (в no-preference media),
`@keyframes tch-in`, `.sec-head h2.t-done .tch` — удаляются. Титулы
секций всегда целые (reveal-каскад `.rv` остаётся).

## Критерии приёмки

1. Лендинг: нет штрих-кодов, ▸, LIM/номеров; заголовки и теги без
   свечения; титулы появляются без допечатки; фон заметно спокойнее;
   каретка мигает; прогресс-линия и частицы диаграммы светятся как
   раньше. Консоль: без ▸ и свечения статов.
2. Тексты страниц дословно прежние (минус декоративные SEQ/LIM/номера).
3. `node --check front.js`; тесты 58/58; ноль ошибок консоли браузера;
   переполнений нет на 375/1280.
4. Скриншоты до/после не требуются — пользователь смотрит вживую; мерж и
   деплой по подтверждению.

## Вне объёма

Палитра, композиция блоков, тексты, вращение ДНК, параллаксы, каскады
появления, прогресс-линия, консольная симуляция.
