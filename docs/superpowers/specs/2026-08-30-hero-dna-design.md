# Новая фоновая ДНК-спираль hero (вариант C «Техно-минимализм»)

Дата: 2026-08-30. Статус: вариант C выбран пользователем в visual
companion из трёх сгенерированных (A классика / B нуклеотиды / C техно).

## Что меняется

Текущий `.hero-ghost` — увеличенный логотип S1 (один перекрест, 7 штрихов,
viewBox 240×240, поворот −42°) — выглядит разреженно на 620px. Заменяется
на математически ровную двойную спираль: **4 витка**, тонкие пряди,
передняя ярче (w 2.8, opacity .95), задняя тоньше пунктиром (w 2,
opacity .38, dasharray 7 9), короткие перекладины (w 1.8, opacity .55)
только в широких местах витков. viewBox 0 0 260 720. Готовая разметка
генерируется скриптом (детерминированная синусоида) и вставляется в
index.html литерально; точный SVG — в плане реализации.

## Посадка в hero

- CSS `.hero-ghost`: ширина `min(32vw, 400px)` (вместо `min(46vw, 620px)`
  — новая спираль вытянутая, 260:720), позиция `top: 2%; right: -2%`,
  базовый наклон `transform: rotate(-28deg)`; `opacity: .09` и
  `pointer-events: none` сохраняются; скрытие ≤900px сохраняется.
- front.js hero-ghost параллакс: строка записи transform дополняется
  постоянным поворотом — `"translateY(…px) rotate(-28deg)"`, чтобы наклон
  не терялся при первом скролле (при REDUCED параллакса нет — наклон
  живёт в CSS).
- Логотип в шапке (`.hd-mark`) и консоль не меняются.

## Критерии приёмки

1. Hero: за текстом — плотная ровная спираль на всю высоту секции,
   диагональ ~-28°, прозрачность как раньше; параллакс работает и наклон
   сохраняется при скролле; при reduced-motion спираль статична и наклонна.
2. ≤900px спираль скрыта (как сейчас); переполнений нет.
3. Тесты 58/58; ноль ошибок консоли; скриншот пользователю; деплой на
   прод по подтверждению.

## Вне объёма

Логотип шапки/консоли, DNA-блок «LIMITS IN THE DNA», анимация вращения
спирали, изменение прозрачности/палитры.
