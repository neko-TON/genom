# Механика «EVERY 24 HOURS» → компактные карточки (вариант B)

Дата: 2026-08-30. Статус: вариант B выбран пользователем в visual
companion (против A «пайплайн»); тексты-выжимки утверждены в мокапе.

## Что меняется

Ledger из 7 плотных шагов (`ol.ledger` в секции #how) заменяется сеткой
из 7 компактных карточек в языке блока лимитов. Заголовок секции
(`01 THE ROUTINE THAT RUNS EVERY 24 HOURS` + штрих-код) не меняется.

Каждая карточка: mono-номер (`00`…`06`, УФ), крупный mono-тег (герой),
короткий заголовок, ОДНА строка описания. Утверждённые тексты (дословно):

| № | Тег | Заголовок | Строка |
|---|-----|-----------|--------|
| 00 | `pons v2` | Born on Pons V2 | Bonding curve → Uniswap v4. Liquidity locked forever. |
| 01 | `80 / 13 / 7` | 3% on every trade | 80% basket · 13% agent · 7% protocol. |
| 02 | `bal × t` | Share = balance × time | No snapshots. Claim anytime. |
| 03 | `keccak256` | Decisions locked first | Sealed as a hash before anything moves. |
| 04 | `8 checks` | The vector is vetted | Fail one → epoch voided. |
| 05 | `1 batch` | One atomic batch | Bad slippage reverts all. |
| 06 | `N + 1` | Thesis re-hashed | Failures are public, forever. |

Это сжатые версии прежних абзацев — новых утверждений нет, детали
намеренно опущены по запросу пользователя («не используй ёмких текстов»).

## Вёрстка и стиль

- `.mech-grid`: 4 колонки (7 карточек → ряд 4 + ряд 3), gap 10px;
  ≤1060px — 3, ≤760px — 2, ≤480px — 1 колонка.
- `.mcard`: рамка/фон как `.gene` (единый язык); номер — 9px УФ с
  `--glow-uv`; тег — mono 700 14px `--ice` c `--glow-gs`; заголовок —
  Inter 600 12.5px `--ink`; строка — 11px `--dim`.
- Каскад появления: карточки `.rv` + `--d`-лесенка ~70ms на карточку
  (внутри существующей no-preference media), по образцу gene-grid.
- Чистка мёртвого кода: CSS `.ledger`-правил (сам список, hover-эффекты,
  `.no`/`.kpi`, мобильное скрытие `.kpi`, лесенка `.ledger li.rv` из
  scroll-polish, ховеры из sequencer-блока) — удаляется всё, что
  ссылается на `.ledger`/`.kpi`; `seq-hl`-обёртки прежних абзацев уходят
  вместе с текстами (класс `.seq-hl` остаётся — используется в hero).

## Критерии приёмки

1. Десктоп: 4+3 карточки, каскад; 1060/760/480 — сетка складывается без
   переполнений; заголовок секции и штрих-код нетронуты.
2. Тексты карточек ровно из таблицы выше; в файлах не осталось
   `.ledger`/`.kpi`-селекторов и старых абзацев шагов.
3. Reduced-motion: карточки статичны и видимы. Тесты 58/58; ноль ошибок
   консоли; скриншоты; мерж и деплой по подтверждению.

## Вне объёма

Заголовок секции, штрих-код, остальные блоки, консоль, новые анимации
сверх rv-каскада.
